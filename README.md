# Skyfront Strategy

Mobile-first turn-based strategy game built with Phaser 3 and Capacitor 7.

## Controls
- Tap a blue squad to select it.
- Choose Move, Defend, or Attack.
- Tap a free tile to move; tap an enemy in attack mode to attack.
- Recruit squads, research upgrades, and end the turn.
- Save/load uses device-local storage.

The Android debug APK is built by the GitHub Actions workflow.
